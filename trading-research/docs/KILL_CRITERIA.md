# Universal Kill Framework

These criteria apply to **every** experiment in addition to its per-spec criteria.
They are evaluated in order; the first triggered criterion decides. Verdicts are
recorded in the experiment spec's status log with the evidence that triggered them.

| # | Failure condition | Decision |
|---|---|---|
| 1 | Net out-of-sample expectancy ≤ 0 using aggressive bid/ask execution | **Kill** |
| 2 | Model requires data not observable at decision time | **Kill immediately** (look-ahead) |
| 3 | Limit-order P&L requires assuming every touched order fills | **Invalid backtest** — redo or kill |
| 4 | Midpoint option fills essential to profitability | **Kill** unless real fill data prove attainability |
| 5 | Result appears only after many threshold/feature trials and fails multiplicity correction | **Kill** |
| 6 | Result exists only in the original paper's sample period | **Kill** |
| 7 | 2023–26 performance has opposite sign without a pre-specified regime explanation | **Kill** |
| 8 | Out-of-sample Sharpe < 0.5 | **Usually kill** (exception: unusual diversification value, documented) |
| 9 | More than half of gross alpha disappears at half-spread + realistic fees | **Severe downgrade** |
| 10 | Profit generated by < 5% of observations | Investigate tail/event dependency; **usually downgrade** |
| 11 | Removing microcaps eliminates the result | **Kill for retail deployment** |
| 12 | Short availability missing in a material fraction of intended positions | Remove short leg or **kill** |
| 13 | Tail risk dominates average return | Re-engineer with defined risk or **kill** |
| 14 | Capacity below intended account size | **Kill** |
| 15 | Live paper fills differ materially from simulated fills | **Stop deployment**; recalibrate execution model |

## Statistical standard

- Conventional |t| = 1.96 is indefensible after multiple candidate strategies.
  Discovery thresholds: **|t| ≥ 3.8** (time-series) / **|t| ≥ 3.4** (cross-sectional),
  or explicit false-discovery-rate control across the programme's full trial count.
- Bootstrap by **event/date clusters**, never individual trades.
- Report pre- vs post-publication returns separately for any published anomaly.
  Where < 1 year of post-publication data exists, record
  "post-publication evidence unavailable" — do not interpret the sliver.

## Process rules

- Kill criteria are written into the spec **before** the backtest runs.
- A triggered kill is final for that experiment ID. Learning from a kill and
  registering a materially different follow-up (new ID) is encouraged;
  quietly re-running the same idea with softened thresholds is not.
- Nobody gets to grade their own homework silently: every verdict, pass or kill,
  is committed to the spec's status log with the numbers that produced it.
